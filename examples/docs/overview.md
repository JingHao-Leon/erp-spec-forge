# 生鲜供应链 ERP（示例规格）

以 YAML 规格驱动建模的生鲜供应链 ERP：基础主数据、采购、销售、库存、配送、结算、溯源与系统管理八大领域。

- 规格版本：`0.1.0`
- 领域数：8
- 实体数：46
- 单据状态机：3
- 角色：9
